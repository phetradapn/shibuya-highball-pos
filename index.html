☁️ เชื่อมต่อออนไลน์ (Firebase)

เชื่อมต่อกับ Firebase Realtime Database ฟรี เพื่อให้ยอดขายและสต็อกจากทุกบูธ/ทุกเครื่องอัปเดตมารวมกันแบบเรียลไทม์

📖 วิธีสร้างลิงก์ Firebase ฟรี (ใช้เวลา 1 นาที) ▼
  1. ไปที่ console.firebase.google.com และสร้างโปรเจกต์ใหม่
  2. เลือกเมนูซ้าย Build > Realtime Database กด Create Database
  3. เลือกโหมด Start in test mode (อนุญาตให้อ่าน/เขียนข้อมูล)
  4. คัดลอกลิงก์ URL ด้านบนสุด (เช่น https://xxx.firebaseio.com) มาวางในช่องด้านบน แล้วกดบันทึก
  5. กดปุ่ม ดาวน์โหลดไฟล์แอป POS (.html) ในหน้าหลังบ้านส่งให้บูธอื่นเปิดใช้งานได้เลย!
